# DisagreementView

Two agents' answers to the same question, side by side, so a person can decide. Each column keeps the result card's three parts: calculated fact, interpretation, limitations. A band underneath names exactly where they differ.

**Consumer provides:** both results with attribution, the shared `PinnedSnapshot` (or a `caution` notice when the pins differ), the differing words marked with `<mark>`, and the decision actions.

- Agents don't vote and don't settle it between themselves. A person picks: **Use Mat's**, **Use Grace's**, **Keep both on the chart** (each attributed), or **Ask in the conversation**.
- The difference band says what kind of difference it is: definition, data, method, or interpretation. A difference in data (different pins or adjustments) blocks the comparison until both are re-run on one pin.
- Underlined marks never rely on colour alone.
- Below 520px the columns stack, Mat first, in the order the results arrived.
