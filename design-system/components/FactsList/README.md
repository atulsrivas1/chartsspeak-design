# FactsList

A definition list of facts (term in `label` style, value in `numeric`), used in the Data tab, the hover readout and dialogs.

**Consumer provides:** a `<dl class="cs-facts">` of `dt`/`dd` pairs.

- Terms are short nouns. Values use the fixed data-honesty vocabulary where it applies.
- Not for anything you can operate. Use `Field` for that.
