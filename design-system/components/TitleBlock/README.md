# TitleBlock

The page heading: an eyebrow, the symbol and date range in `title-page`, the `SaveStateChip`, and one line describing the data.

**Consumer provides:** the eyebrow text (an uppercase `label`, set in CSS rather than typed in capitals), the title, the save state and the data line; Reconnect appears here only when the connection is lost.

- The data line uses the fixed vocabulary and states coverage ("stored through …").
- One title block per screen. On phone `title-page` drops to 21/26.
