# AppShellDemo

The public read-only demo in the same shell: `DemoBanner` under the top bar, "Read-only demo" tag, no save state, no edit controls, and the composer replaced by one sentence.

**Consumer provides:** the same regions as `AppShell`, with the banner added and the editing controls left out (not disabled).

- Leave the controls out rather than greying them. The demo shows what you can do (look, hover, pan, zoom), not a list of what is locked.
- The data class reads Delayed everywhere it appears.
