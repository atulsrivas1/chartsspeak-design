# FirstRunChecklist

The first-run guide: four honest steps from sign-in to a first answer, centred in the empty chart panel.

**Consumer provides:** a `cs-card` with an eyebrow, a headline, and a `cs-checklist` (`data-state` done/now on items); the current step's body holds a `CommandCopy` when the step needs the data utility.

- The headline states the product rule up front: only stored data is shown.
- Steps complete themselves from real state (a stored symbol exists, a chart was opened). Nothing is ticked for show.
- Dismissible after step 3. It never returns once a chart has been opened.
