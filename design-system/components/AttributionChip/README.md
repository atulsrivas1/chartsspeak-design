# AttributionChip

Who made a change, and when, on every shared item: layers, notes, evidence and assistant additions.

**Consumer provides:** a `cs-attr` with a `cs-avatar` (assistant: accent ring; person: `cs-avatar--person` with initials) and "<name> · <verb> <time>".

- The assistant's avatar is the only place `accent-wash` marks identity. Use it consistently, and do not decorate a person's avatar the same way.
- "Hidden in your view" replaces the verb when you have hidden an assistant addition. It is presentation only and changes nothing shared.
- For the multi-person future (W2) the same chip names invited people. Presence dots are not defined yet.
