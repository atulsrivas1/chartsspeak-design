# DemoBanner

The public demo's data statement, full width under the `TopBar`, with the chart selector when several charts are offered.

**Consumer provides:** a `cs-banner` with `role="note"`, a `DataClassBadge`, the fixed sentence and an optional chart `select`.

- The sentence is fixed: "Delayed, stored daily data, read-only, for demonstration only. Not investment advice."
- The banner cannot be dismissed in the demo.
