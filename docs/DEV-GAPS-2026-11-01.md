## Contract changes for the Architect

These touch KA2/KA3 or the view contract, so they need a ruling before the stories above are Ready.

- **One proposal per task**, holding several changes the person can apply all or in part (AA-9, AA-17).
- **A per-agent "apply without asking" flag**, limited to additions on private charts, with an audit line for each auto-applied change.
- **A selection field on agent requests**: the chosen bars (symbol, from, to, count), so the agent gets exact bars instead of a date guess.
- **People as request recipients**: the same request record as for an agent, plus "seen" and presence.
- **One action registry**: the toolbar, context menu, palette and later voice all read the same list of actions and their keys.
